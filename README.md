# Canlow

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**Canlow** 是一款开源的 AI 编程助手桌面应用，基于 **Tauri 2 + Rust + React 19** 构建：轻量（打包约 10-20MB）、启动快、内存占用低。它将 AI 对话与「任务图」工程模式深度融合——AI 先规划出结构化的任务图（任务目标 → 任务总结 → 方法步骤 → 细分层级），再严格按照计划执行，每个任务带唯一层级编号，开始前/完成后都会重新核对任务表，杜绝执行混乱。

核心特色：

- **计划确认机制**：AI 创建或修改任务结构后必须经你确认才继续执行，进度更新则自动完成——人机协作，全程可控
- **四档授权模式**：逐次询问 / 智能 / 仅确认计划 / 全自动，按需选择监管强度
- **任务设计对话框**：发送需求自动包装为任务规划指令，AI 先调整任务图再征求同意
- **上下文缓存友好**：遵循 Codex 上下文纪律，长对话不卡顿、API 缓存命中率高
- **内置工具集**：文件读写、代码搜索、Git、命令执行（含安全拦截）、联网搜索、任务图规划

技术栈：Tauri 2 / Rust / React 19 / TypeScript / React Flow / SQLite。MIT 协议开源。

## 功能特性

- 💬 **对话**：流式输出、思考过程展示、工具调用卡片（可折叠）
- 🗺️ **任务图（工程模式）**：AI 按「任务目标 → 一级任务总结 → 方法步骤 → 细分」的层级语义规划并严格执行，每个任务节点带层级编号（a1 → a1b1 → b2c1），开始/完成后 AI 都会重新阅读任务表防混淆
- ✅ **计划确认**：AI 创建/修改任务图结构（创建、加子任务、调顺序、移动、删除、改需求）后，无论授权模式如何，都会弹窗等你确认才继续执行（进度更新无需确认）
- 🎛️ **四档授权模式**：
  | 模式 | 工具授权 | 计划确认 |
  |---|---|---|
  | 逐次询问 | 每次询问 | ✅ |
  | 智能（只读自动） | 只读自动 | ✅ |
  | 仅确认计划 | 全部自动 | ✅ |
  | 全自动 | 全部自动 | ❌ 直接执行 |
- 🎮 **任务图控制**：打断 / 继续 / 刷新 / 自动整理布局，节点不可拖拽（布局由 AI 生成与整理功能维护）
- 📋 **任务设计对话框**：发送内容自动包装为「任务设计/创建指令」，AI 先规划调整任务图、征求同意后才执行
- ⚡ **上下文缓存友好**：固定 system 前缀、历史纯追加、延迟压缩、压缩保留用户消息——参考 Codex 的上下文纪律
- 🔍 **内置工具**：文件读写、搜索（grep/glob/文件名）、Git、命令执行（含安全拦截）、联网搜索、任务图规划（plan_*）

## 技术栈

| 层 | 技术 |
|---|---|
| 桌面壳 | Tauri 2（系统 WebView，打包约 10-20MB） |
| 前端 | React 19 + TypeScript + Vite |
| 消息列表 | @tanstack/react-virtual（虚拟滚动，长对话不卡） |
| 任务图 | React Flow（节点/连线/缩放） |
| 后端 | Rust + reqwest + tokio（流式 API、文件、命令） |

## 核心设计：缓存友好的上下文机制

`src/lib/chat.ts` 从第一天就按 Codex 的纪律实现：

1. **系统提示固定**：永远在开头，内容不变
2. **历史纯追加**：发送请求前不重写任何旧消息
3. **延迟压缩**：只有超出窗口上限才压缩
4. **压缩保留用户消息**：全部用户消息原文（预算内）保留，AI 过程替换为摘要放最后

Rust 侧（`api_stream`）不做任何消息改写，只负责流式转发和透传 usage（含 `prompt_cache_hit_tokens`），为缓存命中率统计留好接口。

## 任务图层级语义（工程模式）

```
任务目标（root，唯一总节点，高于一级）
└── 一级任务 = 任务总结（对任务的总结，挂在 root 下）
    └── 二级任务 = 完成一级任务的方法步骤
        └── 三级任务 = 进一步细分，以此类推
```

- 一级任务编号 `a1`、二级 `a1b1`、三级 `b1c1`……编号 = 父任务自身编号段 + 本级字母 + 全局递增数字，防止混淆
- 后续对话新添加的一级任务（包括差异大的新需求）一律挂在任务目标总节点之下

## 配置

- **API Key**：首次启动后在「设置」中配置提供商与密钥（密钥仅存本地，不随项目分发）
- **工作目录**：会话工具栏可设置项目文件夹（工具操作限定在该目录内，防路径越界）
- **授权模式**：顶部可切换逐次询问 / 智能 / 仅确认计划 / 全自动
